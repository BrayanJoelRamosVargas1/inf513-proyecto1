# Figuras vigentes del PUDS

Estas fuentes corresponden al PUDS reconstruido con el formato del Grupo 05SA.
Conservan los ocho casos aprobados y las clases, métodos y columnas del Grupo 09SA.

La carpeta incluye fichas de CU, paquetes y sus vistas, colaboraciones,
secuencias, clases, arquitectura y datos. Los paquetes funcionales son vistas de
análisis; los paquetes Java y sus responsabilidades se explican en el PUDS.
Las asociaciones del modelo de datos representan FK reales. Las relaciones
entre clases Java siguen la implementación, aunque la arquitectura del otro
grupo utilice nombres y divisiones diferentes.

Los archivos DOT y SVG son editables. Los PNG se insertan en el documento.
MODELO_DATOS_AMPLIADO.pdf permite leer e imprimir las dos vistas de datos
por separado en A2; el PUDS principal conserva exclusivamente páginas A4.
El escudo FICCT procede de la portada del PDF de referencia y se utiliza para
identificar la misma facultad; autores, proyecto y gestión son del Grupo 09SA.
